Paths below were checked in September 2026 against Android 17, iOS 27, Windows 11 version 25H2 and macOS 27 Golden Gate. Wording shifts between versions and between phone makers — if a path doesn't match yours, search the settings app for the feature name.

None of this is only for people with a diagnosis. Captions get used on a loud train, magnification in bright sun, mono audio when one earbud dies. Turning one on for a week is the fastest way to understand what a colleague relies on all day — and to notice which of the things we build quietly break when it's on.
